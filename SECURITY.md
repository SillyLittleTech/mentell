# Security Policy

## Supported Versions

The below table shows versions of Mentell that are still being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.18.x   | :white_check_mark: |
| 1.17.3x   | :white_check_mark: |
| 1.17.6   | :x:                |
| 1.17.5   | :white_check_mark: |
| < 1.16.x   | :x:                |

## Reporting a Vulnerability
